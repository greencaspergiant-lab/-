# 写真台帳 自動作成（GAS）

Google Drive の案件フォルダに写真を入れると、10分以内に「納品」フォルダへ Excel / PDF の写真台帳を出力します。

## フォルダ構成

```
写真台帳（ルート）
└ 桜坂ハイツ101_原状回復工事        ← 案件フォルダ「物件名_工事名」
   ├ 01_洋室_クロス剥がれ.jpg
   ├ 02_浴室_コーキング劣化.jpg
   └ 納品                            ← 自動作成
      ├ 桜坂ハイツ101_原状回復工事_写真台帳.xlsx
      └ 桜坂ハイツ101_原状回復工事_写真台帳.pdf
```

- 1ページ3枚（A4縦）。左に写真、右に No.／撮影日（EXIF）／場所／内容／備考
- ファイル名 `連番_場所_内容` から場所・内容を自動入力（IMG_xxxx のままなら空欄）
- Drive で写真の「説明」を入れると備考欄に反映
- 写真の追加・差替え・説明変更を検知して自動で作り直し（旧版はゴミ箱へ）
- 最後の追加から10分待ってから作成（アップロード途中で作らない）

## 設定手順

1. Drive に「写真台帳」フォルダを作成し、URL末尾のフォルダIDを控える
2. https://script.google.com で新規プロジェクト作成
3. `Code.gs` を貼り付け、`CONFIG.ROOT_FOLDER_ID` にフォルダIDを入力
4. プロジェクトの設定 →「appsscript.json をエディタで表示」にチェック → `appsscript.json` を貼り付け
5. `setup` を1回実行して権限を承認（10分おきの自動実行が登録される）
6. 即時作成したいときは `rebuildAll` を実行

## 注意

- Excel は 1ページ＝1シート（P1, P2…）。PDF は全ページ1ファイル
- 1回の実行は約4分で打ち切り、残りは次回（写真が非常に多い案件は2〜3回に分かれる）
